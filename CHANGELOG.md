# Changelog

## 0.002 · 2026-10-28

- Cyrillic U+0400–045F, 96 letters: Serbian and Macedonian with `locl` forms, Russian, Belarusian, Bulgarian, Ukrainian except Ґ ґ.
- 927 glyphs, 879 codepoints (from 828 · 783).
- `ss02`: an l with slabs on both sides. `ss01` is now the vertical-bar zero; the default zero has a diagonal marker.
- Line metrics: the baseline sits nine units lower at the same 1332-unit pitch (1093 / −239), so no accent or descender clips at 9–24 px.
- `ø Ø` take the genre's slash, steep and past the bowl (the e/ø margin rises 24%); `æ` has two balanced counters instead of a slit eye; the zero, `1 K Y y у` joins refined.
- Same license (1.2) and name records; version 0.002 so installed copies refresh.
